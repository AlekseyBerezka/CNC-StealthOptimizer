# 🛠 CNC-StealthOptimizer

**Аудитор управляющих программ для токарных станков Fanuc.**  
Структурная безопасность + рекомендации ИИ. Без правок технологии.

---

## 🎯 О проекте

`CNC-StealthOptimizer` — это инструмент, который соединяет практический опыт наладчика ЧПУ с современными возможностями анализа данных. Он предназначен для проверки управляющих программ (УП) перед запуском на станке.

**Что делает инструмент:**
1.  Считает честное машинное время цикла: резание, быстрые ходы, сверление и смены инструмента.
2.  Гарантирует структурную безопасность УП:
    *   `M30`/`M02` — ровно один раз, всегда в конце основной программы.
    *   Перед каждым вызовом инструмента (`T`) проверяет наличие безопасного отхода.
3.  Предоставляет рекомендации технологу через локальную LLM (Ollama), не изменяя код автоматически.

**Что инструмент НЕ делает (принципиально):**
*   ❌ **Не переставляет инструменты.** Повторный вызов инструмента — это часто технологически обоснованное решение.
*   ❌ **Не удаляет и не оптимизирует проходы.** Экономия секунд не стоит риска брака.
*   ❌ **Не меняет режимы резания.** Это ответственность технолога.

> **Философия:** ИИ даёт советы. Технолог принимает решения. Python проверяет, чтобы никто не сломал станок.

## 🏗 Архитектура

Проект состоит из нескольких модулей, каждый из которых отвечает за свою задачу:

| Файл                     | Роль                                                                 |
| ------------------------ | -------------------------------------------------------------------- |
| `core/time_estimator.py` | Оценка машинного времени: `G01/G02/G03`, `G00`, `G96/G97`, смены `T`. |
| `core/safety_validator.py`| Жёсткие проверки: `G50 S0`, `G96` без `G50`.                         |
| `core/compiler.py`       | `M30` в конец, вставка кадров безопасного отхода перед `T`-вызовами.   |
| `core/ai_auditor.py`     | Запрос к Ollama, парсинг JSON, отчёт для технолога.                  |
| `core/pipeline.py`       | Оркестратор: управляет потоком данных между модулями.                |
| `app.py`                 | CLI (интерфейс командной строки) для запуска аудита.                 |
| `streamlit_app.py`       | Веб-витрина для наглядного отображения результатов.                  |
